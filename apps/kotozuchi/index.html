Kotozuchi

ブラウザ

RFC の英文・数字・記号を打って、打鍵を鍛えるタイピング練習ゲーム

名前は「言（こと）」＋「槌（つち）」＝「言槌（ことづち）」から。言葉を打って打鍵を鍛えることより。

どんなゲーム？

  • 画面に出る文字を、制限時間の中で正しく打っていくタイピング練習ゲーム。
  • 出題は「文章」「数字」「記号」の3つのモードから選べます。
  • 文章モードは、インターネットの取り決めを書いた文書「RFC」の本文から、英文を1文ずつそのまま出題します。
  • 数字モードは 0〜9 の並びを、記号モードは ASCII の記号32種を出題します。

打ち方

  • 正しいキーを押すと次の文字へ進みます。間違えても消す操作は要らず、正しいキーを押せば先に進みます。
  • 間違えた文字には印が残り、何のキーを打ってしまったかも表示されます。
  • 次に出る行が薄く先に表示されるので、行の切れ目で手が止まりにくくなっています。
  • 制限時間は最初の1文字を打ったときから動き出します。

操作

  • メニューでは ↑↓ で項目を選び、←→ でモードや制限時間を変え、Enter で始めます。
  • 制限時間は 15秒 から 10分 まで、9段階から選べます（はじめは 1分）。
  • 打っている途中は、Esc で中断、Tab で今の行をとばせます。
  • IME（日本語入力）はオフにして遊んでください。

けっか

  • 正しく打てた文字数・打ち間違い・とばした文字・正確率・速さ（1分あたりの文字数と語数）・打ち終えた行が表示されます。
  • スコアは「正しく打てた文字数 × 正確率」です。速くても間違いが多いと伸びません。
  • とばした文字も正確率に含まれるので、難しい行をとばして正確率を上げることはできません。

技術情報

  • Go + Ebitengine で書き、WebAssembly にしてブラウザで動かしています（同じコードでデスクトップ版にもなります）。
  • 画面は論理解像度 640×480。文字は 12px のビットマップフォント（bitmapfont）で描画します。
  • キーの位置ではなく、OS やブラウザが解釈した後の文字で入力を受けるため、JIS 配列でも US 配列でも刻印どおりに打てます。
  • 出題文は、著作権表示の無い 1997 年以前の RFC から自作ツールで抽出。固定幅の折り返しとページのヘッダ・フッタを除くだけで、語句は書き換えていません。抽出した文はバイナリに埋め込み。
  • GitHub Actions で main への push ごとに、テスト → WASM ビルド → GitHub Pages への配信を自動で行います。
