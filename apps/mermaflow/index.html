Mermaflow

Windows

git リポジトリのコミット履歴から Mermaid の gitGraph を生成するデスクトップアプリ

名前は「Mermaid」＋「Git」の流れ（フロー）を可視化することから。

どんなアプリ？

  • git リポジトリのコミット履歴から、Mermaid の gitGraph 記法を自動生成するデスクトップアプリ。
  • 指定したリポジトリのブランチ一覧から好きなブランチと期間を選ぶと、条件に合う履歴を図として可視化。
  • 左にマークダウン（編集可能）、右にライブプレビューが並び、その場で見た目を確認できます。

できること

  • リポジトリの指定は SSH（鍵／パスワード／ssh-agent）と HTTP(S)（Basic／トークン）の両方に対応。
  • ブランチは複数選択可能（先頭に選んだブランチが基準ブランチになります）。
  • 期間は「全期間」か「開始日〜終了日」で絞り込める。
  • 生成したマークダウンや、プレビューの PNG／SVG をクリップボードコピーやファイル保存できる。
  • 図は縦長（TB）・横長（LR）を切り替えられ、プレビューは拡大縮小も可能。

セキュリティ

  • 入力した SSH 鍵・パスワード・トークンはディスクに保存されません。
