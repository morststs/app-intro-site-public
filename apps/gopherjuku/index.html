Gopherjuku

ブラウザ / Windows

Go のサンプルコードをその場で編集・実行しながら学ぶ学習アプリ

名前は Go のマスコット「Gopher（ゴーファー）」＋「塾（じゅく）」から。

どんなアプリ？

  • Go 言語のサンプルコードを、その場で編集して実行し、結果を見ながら学べる学習アプリ。
  • 説明はソースコードのコメントに書かれていて、「読む → 動かす → 理解する」の順で進められます。
  • ブラウザ版（インストール不要）と、Windows 用のデスクトップ版（単体 .exe）の2通りで使えます。

画面

  • 3ペイン構成。左がレッスンツリー（カテゴリーはアコーディオンで開閉）。
  • 中央がエディタ（Go の構文ハイライト付き）。
  • 右が実行結果（標準出力・エラー）の表示エリア。

操作

  • 「▶ 実行」でコードを動かし、結果を右ペインに表示。
  • 「Shift + Alt + F」で gofmt によるコード整形。
  • 「Ctrl + マウスホイール」でエディタや実行結果の文字サイズを変更。

収録レッスン（計29）

  • 基本 … ハローワールドや変数・型、制御構文、関数、構造体、インターフェースなど。
  • 標準ライブラリ … fmt / strings / strconv / sort / time / errors / JSON / regexp など。
  • 応用 … 型スイッチ、埋め込み、defer・panic・recover、goroutine と channel、ジェネリクスなど。
