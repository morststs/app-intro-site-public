Sirusita

Windows / ブラウザ

マークダウンで手軽に書ける、シンプルなメモアプリ

名前は「マーク」＝印（しるし）、「ダウン」＝下（した）を合わせた「記した（しるした）」から。

どんなアプリ？

  • シンプルなメモアプリ。Windows アプリ版（Microsoft Store）と、インストール不要の Web 版があります。
  • メモは「マークダウン」（# や - などの記号だけで見出しや箇条書きを表せる、手軽な書き方）で書けます。
  • 書いたメモはパソコン内（Web 版はブラウザ内）にだけ保存され、外部に送られることはありません。Windows アプリ版はインターネットにつながなくても使えます。

できること

  • 「編集」「プレビュー（清書された見た目）」「分割（左右に並べて表示）」をタブで切り替えながら書ける。
  • 数式や図（Mermaid / D2）、色付きのプログラムコードもプレビューで表示できる。コードはボタン一つでコピーできる。
  • プレビューの文字サイズを変えたり、見出しの一覧から読みたい場所へジャンプしたりできる。
  • 書いた内容は自動で保存されるので、保存ボタンはありません。

タグで整理

  • メモにタグを付けて、サイドバーから関連するメモだけを絞り込める。
  • 「プログラミング/Go」のように「/」で区切ると階層タグになり、親のタグを選べば配下のメモもまとめて表示されます。
  • タグ名の変更は配下のタグごとまとめて付け替わり、同じ名前にすれば 2 つのタグを統合できる。
  • 一覧で複数のメモを選んで、まとめてタグを付け外ししたり、削除したりできる。

サンプル集とヘルプ

  • 言語の基本文法・コマンド・図や数式の書き方などのサンプル集を同梱。カテゴリー別の一覧から選んで、メモとして追加できます。
  • 使い方はアプリ内の「?」ボタンからいつでも確認できます。

ファイルの読み込み・書き出し

  • 他で作ったマークダウンファイルや、それをまとめた ZIP を読み込めます（複数選択・ドラッグ＆ドロップも可）。
  • 読み込んだメモのタイトルは、ファイル内の情報や先頭の見出し、なければファイル名から自動で決まります。
  • 書き出すと、タイトルを見出しに付けたマークダウンファイルとして保存されます。
  • サイドバーの幅や表示の切り替えなどの設定は、次に開いたときもそのまま引き継がれます。

技術情報

  • Go 1.23 + Wails v2 のデスクトップアプリ。画面は Svelte 5（runes）+ Vite 7、UI は Flowbite Svelte + Tailwind CSS 4。
  • 編集欄は Monaco Editor。プレビューは marked でマークダウンを変換し、highlight.js（コードの色付け）・KaTeX（数式）・Mermaid（図）に対応。表示前に DOMPurify で無害化します。
  • D2 の図は Go 側で D2 ライブラリを使って SVG に変換します。
  • メモは ~/.sirusita/notes/{UUID}.md に、YAML front matter（タイトル・タグ・作成／更新日時）付きのマークダウンとして 1 件 1 ファイルで保存。
  • Web 版は同じ画面をブラウザで動かし、メモは IndexedDB に保存。D2 の描画とインポートの解析は Go を WebAssembly にして Web Worker で実行します。外部の CDN は使いません。
  • v* タグの push で GitHub Actions が Windows 用 exe と Microsoft Store 提出用の MSIX をビルド。main への push で Web 版を GitHub Pages に公開します。
  • ライセンスは MIT。
