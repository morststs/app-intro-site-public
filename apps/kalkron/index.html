Kalkron

Android

標準・関数電卓・プログラマーの3つのモードを持つ、計器のようなデザインの電卓

名前は Kalk（計算）と、計器やクロノグラフを思わせる -kron を合わせた造語。

どんなアプリ？

  • 黒地にシアンの文字で、計器のような見た目の Android 用の電卓アプリ。
  • 画面下のタブで、標準（STD）・関数電卓（SCI）・プログラマー（PROG）・履歴（HIST）を切り替えます。
  • 縦向き・横向きのどちらでも使えます。

できること

  • 標準モードは四則演算・%・符号反転と続けての計算。0.1 + 0.2 が 0.30000000000000004 になるような誤差が出ません。
  • 関数電卓モードは式全体を入力して計算。sin・cos・tan、対数、累乗、角度単位（RAD / DEG / GRAD）の切り替え、数値微分 d/dx と数値積分 ∫ に対応し、入力中も結果を先に表示します。
  • プログラマーモードは 16 進・10 進・8 進・2 進を同時に表示。8〜64 ビットの語長と符号の有無を切り替えられ、AND / OR / XOR などのビット演算やシフト、ビットをタップして反転できるグリッドがあります。
  • 計算した結果は履歴に残り、あとから一覧で見返せます。

インストール

  • 最新リリースから APK をダウンロードしてインストールします（Android 8.0 以降）。
  • Google Play を経由しないため、端末で「提供元不明のアプリ」の許可が必要です。
  • インターネットに接続する権限を持たず、データを一切収集・送信しません。

技術情報

  • Kotlin + Jetpack Compose（Material3）で書いた Android アプリ。構成は MVVM + Repository。
  • 標準モードは BigDecimal で計算。関数電卓は式を字句解析 → 再帰下降パーサーで構文木にして Double で評価し、数値微分は 5 点差分公式、数値積分は適応シンプソン法で求めます。
  • プログラマーモードは 64 ビット整数（Long）で計算し、語長に合わせて桁あふれを切り詰めます。演算子の優先順位は C 言語にならっています。
  • 計算履歴は端末内の Room（SQLite）に保存。画面遷移は Navigation Compose の型安全ルート。
  • 見た目は Google Stitch で作ったデザインシステムに基づき、フォント（JetBrains Mono / Space Grotesk / Geist、SIL Open Font License 1.1）を同梱しています。
  • GitHub Releases で署名済みの APK を配布しています。ライセンスは MIT。
