Kizamiru

ブラウザ

やることのリストを作り、チェックしながら進められる共有チェックリスト

どんなアプリ？

  • やることを並べたリストを作り、上から順にチェックしながら進められるアプリ。
  • 旅行の持ち物、引っ越しの手続き、はじめての作業手順など、抜け漏れを防ぎたいものに向いています。
  • 作ったリストとチェックはこのブラウザに保存されます。アカウントは要りません。

リストを作る

  • 項目には補足を書けます。並べ替えや削除もできます。
  • 題名・作成者・タグを付けて整理できます。
  • どこまで進んだかが件数と割合で表示されます。
  • 項目や説明に書いた URL は、そのまま開けるリンクになります。

人と共有する

  • 作ったリストは公開でき、URL を知っている人がログインなしで開けます。
  • 「みんなの公開リスト」に載せると、誰でも題名やタグから探せます。
  • 載せずに、URL を知っている人だけに配ることもできます（限定公開）。「みんなの公開リスト」には出ません。
  • 開いた限定公開のリストは「限定公開」タブに残るので、URL を無くしても戻れます。
  • 公開したリストを自分の一覧に追加すると、そのままチェックできるようになります。
  • 公開するときだけ Google のログインが要ります。見る・チェックするだけなら要りません。

公開リストは版で固定されます

  • 自分の一覧に追加した公開リストは、追加した時点の内容のままです。作った人が更新しても勝手には変わりません。
  • 新しい版が出るとお知らせします。移るかどうかはご自身で選べます。
  • 移るときは、項目の入れ替えで外れてしまうチェックを先にお見せします。
  • 追加した公開リストを編集すると、自分用のコピーになって自由に直せます（そのかわり公開元の更新は届かなくなります）。

チェックは外に出ません

  • 公開されるのはリストの内容だけです。誰がどこまで進んだかはサーバーに送っていません。
  • チェックは書き出して人に渡せます（Kizamiru 用のファイルのほか、マークダウンや表計算で開ける形式にも書き出せます）。
  • 受け取ったチェックを取り込むと、自分の進み具合と並べて見られます。

技術情報

  • Svelte 5（runes）+ Vite 7 + TypeScript で構築。UI は Flowbite Svelte + Tailwind CSS 4、テストは Vitest。
  • 画面は GitHub Pages から静的に配信（ハッシュルーティング）。公開機能の API だけを Cloudflare Workers に置き、CORS 越しに呼び出します。
  • リストとチェックはブラウザの localStorage に保存。チェック状態は詰めた文字列で保存し、容量を抑えています。
  • 公開リストは内容のハッシュを ID にした変更不可のスナップショットとして Workers KV に保存。同じ内容なら同じ URL になります。
  • 公開時のログインは Google Identity Services。Worker 側で ID トークンの署名・発行元・宛先を検証します。
  • 利用回数の上限は Durable Objects（SQLite）と Rate Limiting で数えています。
  • AI エージェントから操作するための MCP エンドポイント（JSON-RPC、個人トークンで認証）も Worker に用意しています。
